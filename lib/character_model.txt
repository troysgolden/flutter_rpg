Character Model (class)
    -> id (int/string)
    -> name (string)
    -> slogan (string)
    -> isFav (boolean)
    -> vocation (enhanced enum)
        -> image (string)
        -> title (string)
        -> description (string)
        -> ability (string)
        -> weapon (string)
    -> skills (set of type of skills (class))
        -> name (string)
        -> image (string)
        -> descriptions (string)
        -> vocation (Vocation - associated vocation for skill)
        -> id (string/int)
    -> stats (mixin)
        -> health (int)
        -> attack (int)
        -> defense (int)
        -> skill (int)
        -> points (int)
